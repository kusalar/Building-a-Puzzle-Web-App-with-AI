# Building-a-Puzzle-Web-App-with-AI

A cozy, responsive word-search game built with React, TypeScript, and Vite.

## Getting started

```sh
npm install
npm run dev
```

Choose a built-in theme or enter at least three custom words, then select a
difficulty and create a new puzzle. Drag or swipe across letters in a straight
line to find words. Keyboard users can focus a letter and press Enter or
Spacebar to choose the start and end of a word.

Custom words can be separated by commas or new lines. The easy, medium, and
hard grids are 10 × 10, 12 × 12, and 15 × 15, with a matching maximum of 8, 12,
and 16 custom words.

## Checks
